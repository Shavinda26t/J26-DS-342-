# React + Vite Frontend Dashboard

## Overview
Web visualization interface for HDD Failure Prediction & Self-Healing Framework.

## Pages
- **Dashboard**: Integrated fleet overview
- **Fleet Intelligence**: Behavioral drift & GenAI reports
- **Digital Twin**: HDD degradation & RUL state
- **Causal XAI**: SHAP, causal graph & root cause analysis
- **Safe Optimization**: RL storage action monitor

## Running Locally
```bash
npm install
npm run dev
```
