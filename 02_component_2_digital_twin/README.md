# Component 2: Adaptive AI-Driven Digital Twin for HDD Health

## Research Scope
Constructs virtual digital twins for individual HDDs to track degradation curves and estimate Remaining Useful Life (RUL) under dynamic workloads.

## Structure
- `data/`: Independent raw, interim, processed, feature, and split data pipelines.
- `scripts/`: Core detector, RUL predictor, streaming state manager, and analysis scripts.
- `results/`: Outputs including thresholds sweeps, validation CSVs, and figures.
