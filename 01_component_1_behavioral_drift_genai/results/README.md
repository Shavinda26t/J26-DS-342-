# Component 1: Behavioral Drift & GenAI Intelligence for Enterprise HDD Fleets

## Research Scope
Detects fleet-wide behavioral drift in hard disk drives and generates natural language diagnostic reports using generative AI architectures.

## Structure
- `data/`: Independent raw, interim, processed, feature, and split data pipelines.
- `models/`: Trained drift detection models and GenAI checkpoints.
- `src/`: Core implementation modules.
- `config/`: Component specific parameters (`paths.yaml`, `component_config.yaml`).
